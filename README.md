# 轻卸 · AppSweep

**卸载 macOS 应用时，把常见残留列出来供你检查，再一起移入废纸篓；需要时从恢复记录找回。**

[English](README.en.md) · [下载 DMG](https://github.com/fgyg007/appsweep/releases/latest) · [安装指南](docs/INSTALL.md) · [反馈问题](https://github.com/fgyg007/appsweep/issues)

## 它能做什么

把 `.app` 拖到轻卸，或者点击“选择应用”，即可查看应用本体以及当前用户目录中与它关联的配置、缓存和数据。轻卸把候选文件、匹配原因、估算大小列在一起，由你确认勾选后移动到 macOS 废纸篓。

它适合日常第三方桌面软件的卸载整理，不需要后台常驻，也不是“一键清空整个 Mac”的清理器。

| 功能 | 行为 |
| --- | --- |
| 拖放或选择应用 | 接受 `.app`，也可选择已经放进废纸篓但仍存在的应用包 |
| 常见残留扫描 | 检查当前用户 Library 中的配置、缓存、应用数据等常见位置 |
| 展示匹配依据 | 区分应用标识精确匹配、目录名称匹配和沙盒数据 |
| 保守的默认选择 | 名称匹配和沙盒容器默认不勾选；发现同标识应用副本时残留默认不勾选 |
| 移入废纸篓 | 执行前确认，不永久删除，也不自动清空废纸篓 |
| 恢复记录 | 记录每一项的原位置和废纸篓位置，支持恢复且不覆盖已有文件 |
| 基本保护 | 拒绝 Apple 系统应用、自身卸载及符号链接目标；目标应用仍运行时阻止卸载 |
| 本机工作 | 无账号、无上传、无遥测、无联网依赖 |

## 运行环境

- **Apple Silicon Mac（M 系列）**，**macOS 14 Sonoma 或更新版本**。
- 本次 DMG 仅包含 **arm64**，不支持 Intel Mac、Windows 或 Linux。
- 应用界面为**简体中文**，项目文档提供中英文。
- 运行不需要开发环境、账号或网络连接；不安装后台服务。
- 最低部署目标为 macOS 14；实际验证环境为 Apple Silicon / macOS 27.0.1，未逐一验证每个系统版本。

## 下载与使用

1. 从[最新版本](https://github.com/fgyg007/appsweep/releases/latest)下载 `AppSweep-1.0.1-arm64.dmg`。
2. 打开 DMG，将 `轻卸.app` 拖到 **Applications**。推出 DMG，再打开安装后的应用。
3. 先退出要卸载的软件，然后拖入它的 `.app`，或点击“选择应用”。
4. 检查每个候选项的路径与说明。配置与数据可能包含账号、项目或工作记录；只勾选你确定不再需要的项目。
5. 点击“移入废纸篓”，核对确认框中的数量和估算大小。
6. 如需撤销，打开“恢复记录”并点击“恢复”。原位置有文件时不会覆盖；清空废纸篓后无法恢复。

只清理残留时，可以使用仍在废纸篓中的 `.app` 作为扫描入口，并取消应用本体的勾选。如果应用包已经不存在，当前版本不能只凭软件名称进行扫描。

**此版本采用 ad-hoc 签名，未经过 Apple Developer ID 签名或公证。**首次打开可能被 macOS 阻止；请先查看[安装指南](docs/INSTALL.md)，核验来源与校验值，再按系统“仍要打开”流程操作。

## 扫描范围

扫描当前用户 `~/Library/` 中以下目录：

- `Application Support`、`Caches`、`Preferences`
- `HTTPStorages`、`WebKit`、`Saved Application State`、`Logs`
- `Containers`、`Application Scripts`（需手动勾选）

匹配依据是完整 Bundle ID、限定的文件后缀、以主应用标识为前缀的内置扩展标识，以及有限的准确产品名称。不会仅凭厂商名字批量删除。但**名称相同不等于一定属于目标应用**，仍需人工核对。

## 边界与数据安全

- 不保证找到所有残留。Group Containers、隐藏开发配置、Homebrew、系统服务、驱动、浏览器扩展、钥匙串和安装收据不自动处理。
- Docker、VPN、安全软件或含驱动/后台系统组件的软件，应优先使用官方卸载器。
- 副本检测覆盖 `/Applications`、`~/Applications` 和桌面的直接子项；自定义位置和嵌套目录中的副本可能漏检。
- 无法完全识别未知后台进程和共享数据。应用标识匹配也不保证数据不被其他工具使用。
- 受系统权限限制的项目会报告失败，轻卸不提升权限，也不尝试绕过系统保护。大小是估算值，无法读取的目录可能未计入。
- 每次移动后保存恢复记录。若进程恰在移动和写入记录之间中断，可能需要手动从 Finder 废纸篓找回。
- 移入废纸篓不立即释放磁盘空间，工具不会自动清空废纸篓。

恢复记录位于 `~/Library/Application Support/io.jlmac.AppSweep/History/`，包含本工具操作过的文件路径，只存本机。它不是文件备份；不记录其他工具的卸载操作。提交问题时请勿公开含私人路径的完整记录。

## 构建与验证

```sh
git clone https://github.com/fgyg007/appsweep.git
cd appsweep
zsh scripts/test.sh
zsh scripts/build.sh
zsh scripts/package.sh
```

详见[开发说明](docs/DEVELOPMENT.md)。源码不依赖第三方 Swift 包。测试使用临时样本，覆盖精确匹配、名称匹配、共享数据隔离、符号链接、应用副本、系统应用拒绝、失败记录、恢复冲突，以及真正调用 macOS 废纸篓 API 后恢复样本文件。不会卸载真实应用。

已验证核心文件处理、编译和签名；拖放、所有按钮与各系统版本的完整 UI 自动化覆盖仍不充分。
